    Fix: race condition in window resize causing skipped layout passes
    
    The main thread and render thread shared lastClientWidth/Height,
    allowing the render thread to update them before the main thread
    could detect a size change. This caused layout to be skipped after
    maximize/restore, resulting in incorrect grid scaling.
    
    Decoupled the two usages: render thread now uses local variables
    for swap chain resize detection, main thread keeps its own
    lastLayoutWidth/Height for triggering layout rebuilds.
