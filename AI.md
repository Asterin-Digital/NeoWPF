## Human Made Or Vibecoded?

TL;DR
NeoWPF isn't purely vibecoded, but not also purely human made.

The longer answer:

As a single developer that works on NeoWPF with no other team member's, it's very hard to work on such a big project. Sometimes I burnout, make mistakes, and not write such clean code
So for that I use generative AI to:
-Help me refactor code
-Generate user-facing documentation
-Fix bugs
-Plan features

Human reviews are done (both for code and documentation), though, some things may slip under my eye.

Even with that, NeoWPF is mostly human designed and human led, but AI assisted.
